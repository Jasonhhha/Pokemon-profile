# TIDEBOUND 潮汐群岛

王禹浩的个人主页，也是一段可以在浏览器里玩的宝可梦冒险。首页从潮汐环城的 3D 总览进入。环城大道绕中央潮池闭合，沿途经过英伦红砖排屋、档案屋、港湾诊所、电车站和高草绿廊。全城有 50 栋沿街建筑，中央潮汐塔是港口的地标。研究室、车站信号室和东渡口试炼都在城内。城市下方是一座由酋雷姆供能的四层地宫。

## 游玩

- 拖动总览环视整座城市。点击街道可进入并寻路，也可用右上方的「俯瞰环城」按钮在总览和街道间切换。
- 用方向键或 WASD 移动，长按 Shift 跑步。E、空格和回车可以互动。手机上可用方向键、跑步键和 A 键。
- M 打开环城地图。在环城步行图上选择院落、补给站、档案屋、绿廊或渡口，点击「沿街步行」即可出发。途中可以用方向键接管。Q 查看队伍与道具，J 打开图鉴。
- 在街面点击院落里的地标，或走到旁边按 E 观察。西闸的手摇水泵、蕨园的石砌花床、盐市方尖碑和信号场站钟各有一页手记，集齐四页可获得两份伤药。
- 高草会触发野生遭遇。摇晃的草丛更容易遇到少见的宝可梦，部分种类在夜里更常出现。
- 对战中可使用真实招式、伤药、精灵球和换人。队伍保留招式 PP 和体力，到环城的港湾诊所可以恢复。
- 与绿廊陪练切磋可以获得经验。带至少两位伙伴到东渡口，向守望员挑战圆陆鲨。
- 位置、图鉴、队伍和任务会自动保存在当前浏览器。原主页保存过的宝可梦伙伴可作为新冒险的首发。声音可在导航栏开启。

## 本地运行

```sh
npm ci
npm run dev
```

`npm run build` 生成 `dist/`。GitHub Pages 工作流使用 `/Pokemon-profile/` 作为发布路径。安装 Chrome 后运行 `npm test`。

## 素材与参考

探索场景采用 WebGL 2 渲染。潮汐环城的道路、车轨、楼面和岸线沿圆周搭建。高架电车和渡船各沿独立的路线行驶，夜间会点亮街灯和灯塔。浏览器无法使用 WebGL 2 时会显示可交互的 Canvas 2D 环城。港湾战斗取景于城内的外环绿廊，随昼夜切换光照。

地图与图鉴沿用仓库已有的宝可梦图像。对战中的八种宝可梦使用《黑／白》的正面和背面逐帧动画，出场叫声取自 PokéAPI 收录的早期版本录音。地图中的宝可梦按各自的步态和悬浮习惯跟随，并在转身和停步时逐步回到站姿。场景、地图、界面和配乐为潮汐群岛创作。镜头的远近层次和战斗节奏参考了《宝可梦 黑／白》的官方公开资料。招式资料以第五世代为基准，初始招式组合、经验曲线和野外出现概率按群岛的路线设置。

### 潜航堡垒

西栈桥的铜轮控制堡垒浮升。八面排水结束后，从铜轮南侧走上引桥，或点「踏上外壁长阶」。沿扶壁阶梯、泄水拱廊一路下到下层王门。可以用方向键或触屏方向键自己走，在途中停步、折返；也可以点石阶寻路。经过门槛即进入潮枢水殿。途中刷新会从所在台阶继续。

御水长庭与霜冠陵宫各有一条贯穿南北的仪道。两侧回廊绕过蓄水池和冰庭，横桥与仪道相连。分水仪和星图校准盘可以在侧廊操作。霜冠陵宫西侧的升降台往返潮枢水殿。「俯瞰宫殿」可以拖动镜头，点选院内石路后角色会沿通路走过去。M 展开宫殿平面与已走过的金色足迹。地宫右上角的地图键可以打开全城纵剖，查看四层建筑、目前所在楼层和地表负载。三层水庭和陵宫中都能看到由下向上传光的成对采能井。最底层的采能环接在酋雷姆的封印上，能量经上行母线传向地表。观测桥可以降低城市负载、观察供能变化，再恢复供能。

陵廊北端的阶梯通往冰核封印殿。走到观测桥前端按 E，或点「靠近封印」，即可观察通常形态的酋雷姆并将它记入图鉴。它会蓄力、张颌咆哮，冲击从撞点沿罩壁抵达锚柱，抖落冰霜。点击「听它吼叫」可以单独播放原游戏叫声。开启全局声音，还能听到水渠、陵廊与封印殿中的脚步回声。

桥头的「巡查锁链」会向能量罩施加一次脉冲。跟着东侧或西侧的双响走上检修栈道，检查两座绞盘的回摆。找到错齿的锚柱后收紧锁链，回到观测桥选择「复测封印」。修复进度随冒险保存，复测通过后，酋雷姆的图鉴里会留下一条记有锚柱方位的巡检手记。

海宫的层台借鉴了拉妮·基·瓦夫阶梯井，水殿的柱列借鉴了伊斯坦布尔地下水宫。泄洪空间的尺度参考了日本首都圈外郭放水路调压水槽。青铜潮盘及其与封印池的联系是游戏原创设定。[UNESCO 阶梯井资料](https://whc.unesco.org/en/list/922/) · [土耳其文化和旅游部地下水宫资料](https://www.ktb.gov.tr/EN-113825/yerebatan-palace-cistern.html) · [日本国土交通省调压水槽资料](https://www.ktr.mlit.go.jp/edogawa/edogawa00728.html)

酋雷姆沿用通常形态的模型、纹理与《宝可梦 黑／白》叫声。能量罩、机关、受力反馈与咆哮动作由本站制作。兼容模式用同一模型的姿态图集呈现动作。[素材来源与署名](public/assets/kyurem-credits.txt) · [酋雷姆官方图鉴](https://zukan.pokemon.co.jp/detail/0646)
